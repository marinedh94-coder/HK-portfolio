# AI ATELIER

한국경제 AI 교육 개인 포트폴리오입니다.

## 열기
`dist/index.html`을 브라우저로 열면 됩니다. 별도 설치 없이 실행됩니다.

## 파일
- `dist/introduce.html`: My Profile 소개 페이지 (임시 소개 문구를 실제 정보로 교체)
- `dist/article.html`: 기사 목록과 펼쳐 읽는 임시 원고
- `dist/image.html`: 이미지 갤러리와 확대 보기
- `dist/video.html`: 영상 준비 상태와 스토리보드
- `dist/final.html`: 프로젝트 소개와 제작 과정
- `dist/styles.css`: 공통 스타일과 모바일 대응
- `dist/profile.css`: My Profile 및 다섯 개 메뉴·카테고리 스타일
- `dist/assets/atelier.png`: AI 생성 예시 이미지

## 콘텐츠 교체
각 HTML의 본문을 직접 편집하세요. 이미지 파일은 assets에 넣고 src를 변경합니다. 영상은 준비 중 화면을 `<video controls preload="metadata" poster="assets/atelier.png"><source src="assets/my-video.mp4" type="video/mp4"></video>`로 교체할 수 있습니다.

현재는 정적 포트폴리오이며 관리자 로그인, 파일 업로드 또는 서버 저장 기능은 포함하지 않습니다. 자료 추가는 HTML과 파일을 수정하는 방식입니다. 예시 원고는 실제 보도 자료가 아닙니다.
